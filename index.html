📘 Шпаргалка з формулами лекції «Цінова стратегія фірми»
Блок 2. Правило націнки та Індекс Лернера:
• Граничний дохід і еластичність: MR = P × (1 + 1/E) = MC
• Оптимальна ціна: P* = MC × E / (1 + E)
• Індекс Лернера (міра ринкової влади): L = (P − MC) / P = −1 / E
• Оптимальна націнка на MC: m* = −1 / (1 + E)
Блок 3. Модель «3С» та релевантні витрати:
• Нижня межа в короткому періоді: P ≥ AVC (точка закриття)
• Нижня межа в довгому періоді: P ≥ ATC
• Безповоротні витрати (sunk costs, вже понесені FC) не враховуються при прийнятті короткострокових спецзамовлень!
Блок 4. Методи ціноутворення:
• Ціна беззбитковості: P = AVC + FC / Q
• «Витрати плюс»: P = ATC × (1 + m), де ATC = AVC + FC / Q
• Цільовий прибуток: P = AVC + (FC + πціл) / Q
• Тендерне (Sealed-Bid): max E[π] = (P − C) × Pr(перемоги)
Блок 5. Цінова дискримінація 3-го ступеня:
• Правило оптимізації між двома ринками: MR₁ = MR₂ = MC
• Для лінійного попиту P = a − bQ граничний дохід має вдвічі крутіший нахил: MR = a − 2bQ.
• Вища ціна завжди встановлюється на ринку з менш еластичним попитом!
